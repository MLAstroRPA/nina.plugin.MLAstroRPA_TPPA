# MLAstroRPA+TPPA v2.1.0.0

Stable release of the merged **MLAstroRPA + TPPA** plugin, with **PC control over Wi-Fi (WebSocket)**.

**Requires device firmware 1.3.0 or newer**

## ✨ Highlights
- Wireless (PC client) connection — `MLAstroRPA.local` or the device IP directly
- Complete text <-> JSON translator (same behaviour over USB and Wi-Fi)
- Relative distance can be typed from the keyboard: degrees 0–5, minutes/seconds 0–59
- System log, Alarm panel and dock matching the Web UI
- Jog / relative / soft-limit safety, SAVE ALL & REBOOT over Wireless
- Dock/options UI restyle: rounded-triangle movement pad, circular speed buttons, square STOP, circular FORCE STOP in a square frame
- Align error values typed in the dock are sent on **Enter** and pushed to the Web UI instantly

## 🔧 Fixed
- Reset ESP32 over Wireless did nothing
- Settings could keep stale values, and a save could wipe a stored password
- Align direction toggle over Wireless
- CONNECTION tab cleanup (Reset ESP32 next to Connect)
- Align D/M/S changed over Serial were not broadcast — the Web UI needed a page refresh to show them

## ⚠️ Notes
- Wi-Fi password: press 👁 to fetch it from the device; a blank box on save keeps the current value
- An empty AP IP / subnet is auto-repaired to `192.168.4.1` / `255.255.255.0` by firmware 1.3.0
