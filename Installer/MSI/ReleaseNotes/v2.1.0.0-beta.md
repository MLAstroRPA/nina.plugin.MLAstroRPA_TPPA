# 🧪 MLAstroRPA+TPPA v2.1.0.0-beta

Bản thử của v2.1.0.0 (plugin gộp **MLAstroRPA + TPPA**, điều khiển PC qua **Wi-Fi/WebSocket**).
MSI báo version `2.1.0.0`; đây là **pre-release**.

**Cần firmware 1.3.0+**

## ✨ Điểm chính
- Kết nối Wireless (PC client) — `MLAstroRPA.local` hoặc nhập thẳng IP thiết bị
- Translator text <-> JSON đầy đủ (USB và Wi-Fi hành xử giống nhau)
- System log / Alarm / dock giống Web UI
- An toàn jog, relative, soft-limit
- SAVE ALL & REBOOT qua Wireless

## 🔧 Đã sửa
- Reset ESP32 qua Wireless không có tác dụng
- Settings giữ giá trị cũ / có thể xoá mất mật khẩu khi lưu
- Tab CONNECTION gọn lại, Reset ESP32 cạnh Connect
- Toggle hướng align qua Wireless

## ⚠️ Lưu ý
- Mật khẩu WiFi: bấm 👁 để tải từ thiết bị; ô trống khi lưu = giữ nguyên
- AP IP/subnet rỗng sẽ tự sửa về `192.168.4.1` / `255.255.255.0`

## 📦 Asset
- `MLAstroRPA_TPPA_Plugin_2.1.0.0.msi` — cài cho NINA
- `NINA.Plugins.MLAstroRPA_TPPA.dll` — cập nhật thủ công (`%LOCALAPPDATA%\NINA\Plugins\3.0.0\MLAstroRPA-TPPA\`)
