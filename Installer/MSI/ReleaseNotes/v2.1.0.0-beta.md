# MLAstroRPA+TPPA v2.1.0.0-beta

Pre-release of v2.1.0.0 — the merged **MLAstroRPA + TPPA** plugin with **PC control over Wi-Fi (WebSocket)**.
The installer reports version `2.1.0.0` (Windows Installer has no `-beta` suffix).

**Requires device firmware 1.3.0 or newer**

## ✨ Highlights
- Wireless (PC client) connection — `MLAstroRPA.local` or the device IP directly
- Complete text <-> JSON translator (identical behaviour over USB and Wi-Fi)
- System log, Alarm panel and dock matching the Web UI
- Jog / relative / soft-limit safety
- SAVE ALL & REBOOT over Wireless

## 🔧 Fixed
- Reset ESP32 over Wireless did nothing
- Settings could keep stale values, and a save could wipe a stored password
- CONNECTION tab cleanup (Reset ESP32 next to Connect)
- Align direction toggle over Wireless

## ⚠️ Notes
- Wi-Fi password: press 👁 to fetch it from the device; a blank box on save keeps the current value
- An empty AP IP / subnet is auto-repaired to `192.168.4.1` / `255.255.255.0`

- `NINA.Plugins.MLAstroRPA_TPPA.dll` — manual update (`%LOCALAPPDATA%\NINA\Plugins\3.0.0\MLAstroRPA-TPPA\`)
